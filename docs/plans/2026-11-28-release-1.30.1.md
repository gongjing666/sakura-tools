## 发布范围

本批是 1.30.0 之后 beta-1～beta-33 的累计改动，共 123 个状态项（96 个已跟踪文件变更 + 新增文件/证据），核心为：

- A7 权限拆分：`sufm_manage_users` / `sufm_view_audit` / `sufm_manage_sync` 与 `DELETE_FILES` 分离；REST 和页签按页面能力校验；旧站点通过 `sufm_cap_split_version` 一次性给管理员补权。
- 文件空间用户列表并入「审核与处置」：移除 `files-users` 独立路由，队列页统一用户容量、搜索、分页与处罚入口；移动端使用独立紧凑用户卡。
- 后台 UI：能力矩阵整行与粘性首列/图例、队列卡片重排、共享分页当前页统一、粉色实心按钮改为 `#F585AC → #FFD6E5` 樱花淡粉渐变 + 白字。
- Zibll 性能页写路径迁到 REST；移除旧的 `options.php` 表单与 `wp_ajax_` 入口，状态卡与共享提示同步。
- 安全/边界修复：处罚 `days` 负数绕过永久确认、卡片数组与非标量输入、Space/Zibll 设置输入边界、队列聚合与 option 锁。
- 文档：03/10/12/14、AGENTS、发布流程与本次发布记录。
