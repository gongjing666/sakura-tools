NOTES

核对口径

页面显示的是差异，不直接等于「未同步」。

  • 已同步：本地与云端 Key 存在，且大小／修改时间在容差内。
  • 待上传：本地有、云端无；包含排队中的任务。
  • 仅云端：云端有、本地无；不会自动删除，避免误删 CDN 回源文件。
  • 内容不一致：Key 相同但大小或内容（MD5／ETag）不一致，需重新上传或人工核对。
  • 搜索：按对象 Key 任意位置匹配，只输入文件名也能找到；筛选后的条数与分页按匹配结果计算。
  • 危险操作：删除必须二次确认；属于用户文件空间的附件会连同附件记录、本地文件与容量一起删除，其它对象只删云端副本。批量删除会先列出数量与对象。
